# myShop 电商购物平台 · 后端

myShop 是一个多角色电商购物平台，本项目为其后端服务，基于 Java 21 + Maven 构建，采用前后端分离架构，为商城前端 [myShopUI](../myShopUI) 提供业务与数据接口。

## 平台角色

- **买家**：浏览商品、购物车、下单支付、订单跟踪、商品评价、领取优惠
- **商家**：经营概况、商品管理、订单处理
- **管理员**：平台数据看板，以及商品、订单、用户、商家、促销活动的统一管理

## 主要功能

- 用户注册登录与角色权限管理
- 商品分类、搜索、筛选与详情展示
- 购物车、订单结算与支付
- 订单状态流转与售后评价
- 促销活动与优惠券
- 商家中心与平台后台管理
